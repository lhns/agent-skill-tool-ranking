# Discovery sources

The official plugin marketplace and hesreallyhim's list are the only sources worth checking regularly; the install-ranked directories mostly reward bundle size and promotion. Scored 1 to 5 on usefulness for your stack, checked 2026-10-19.

| Rank | Source | Type | Size | Curation | Best for | Score |
| --- | --- | --- | --- | --- | --- | --- |
| 1 | [anthropics/claude-plugins-official](https://github.com/anthropics/claude-plugins-official) | marketplace | 315 plugins | Reviewed for the 53 Anthropic-hosted ones | LSP plugins, security and review plugins, serena | 5 |
| 2 | [hesreallyhim/awesome-claude-code](https://github.com/hesreallyhim/awesome-claude-code) | awesome list | \~245 | Collaborator-only PRs, hand-written blurbs, freshness badges | Harness tooling: safety hooks, sandboxes, status lines | 4 |
| 3 | [punkpeye/awesome-mcp-servers](https://github.com/punkpeye/awesome-mcp-servers) | awesome list | \~4,380 | Low, vendor self-submissions; useful tags | Niche infra via search: Proxmox, Ceph, Zigbee, Swarm | 3 |
| 4 | [skills.sh](https://www.skills.sh/) | install leaderboard | \~500 ranked | Install counts gameable; Snyk, Socket and Gen audit badges per skill | Audit badges before installing | 3 |
| 5 | [VoltAgent/awesome-agent-skills](https://github.com/VoltAgent/awesome-agent-skills) | awesome list | \~1,150 | "Curated, not audited"; vendor-heavy, sponsors, duplicates | Keyword search: KiCad, Home Assistant, OTel, Go | 3 |
| 6 | [wong2/awesome-mcp-servers](https://github.com/wong2/awesome-mcp-servers) | awesome list | \~515 | No PRs; Official tier is a useful signal | Shortlist of official vendor servers | 3 |
| 7 | [anthropics/skills](https://github.com/anthropics/skills) | official repo | 19 skills | High; demonstration quality | Reference format, mcp-builder, skill-creator | 3 |
| 8 | [heilcheng/awesome-agent-skills](https://github.com/heilcheng/awesome-agent-skills) | awesome list | \~230 | Mirror-site links, some mislabeled entries | Official vendor skill sets | 2 |
| 9 | [skillselion.com](https://skillselion.com/skills) | directory | 63k indexed | Same data as skills.sh plus clone detection | Clone census; spotting copies | 2 |
| 10 | [ComposioHQ/awesome-claude-skills](https://github.com/ComposioHQ/awesome-claude-skills) | awesome list | 164 | Vendor-promotional; half are SaaS automation skills | Rarely useful | 1 |
| 11 | [travisvn/awesome-claude-skills](https://github.com/travisvn/awesome-claude-skills) | awesome list | \~30 | Stale; 819 unreviewed PRs | Nothing new | 1 |

**Red flags seen across sources:** zero-star repos with near-million install counts on skills.sh (flowkit-labs, designed-by-ai, 101-skills), name-squatting on popular projects, and 98% of skills on skillselion declaring no license. None of the sources had anything for Scala (cats-effect, fs2, http4s, Ox), Stalwart or Ceph that cleared the gates.
